# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is available at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful and welcoming; harassment, personal attacks, and
discriminatory behavior are not tolerated in any project space (issues, PRs,
discussions, or elsewhere when representing the project).

## Enforcement

Report unacceptable behavior privately to the maintainer via GitHub
(@sharad52). All reports will be reviewed promptly and handled
confidentially. Maintainers may edit, remove, or reject contributions and
may temporarily or permanently ban contributors for behavior that violates
this code of conduct.
